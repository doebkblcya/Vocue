## 2. R9 · AI 仿真面试

复用现有的 JD、简历、补充资料和结构化档案，让 AI 扮演面试官完成一场模拟面试。

### 核心流程

1. 用户选择面试档案并开始仿真面试。
2. AI 根据岗位要求与候选人经历生成问题。
3. 用户通过麦克风回答，系统实时转写并保存真实回答。
4. AI 可以根据回答继续追问，但不能提前泄露参考答案。
5. 每道题保存问题、真实回答和评价。
6. 面试结束后生成总评分、能力维度、薄弱点、改进建议和针对性练习。
7. 仿真面试记录进入现有面试记录体系，支持以后查看与复盘。

### 需要设计的内容

- 面试类型与时长设置。
- AI 出题、用户回答、追问、结束的状态机。
- 逐题评价和整场评价 Prompt。
- 仿真面试进行页与报告页。
- 中断恢复、主动跳题和提前结束。

## 3. R10 · UI 重构

当前界面已有较一致的颜色和组件习惯，但还没有正式的设计系统。UI 重构不只是换颜色，需要统一产品结构和交互层级。

### 重构范围

- 首页与左侧导航。
- 开始面试流程。
- 实时辅助悬浮窗。
- 面试档案管理。
- 面试记录、外放回声清理和 AI 复盘。
- 设置页。
- 新增的 AI 仿真面试与报告页。
- 空状态、加载状态、错误状态和权限提示。

### 视觉规范

- 保留 `lucide-react` 作为统一图标来源。
- 明确正文、标题、数字和品牌字体的使用范围。
- 将颜色、字号、间距、圆角、阴影和图标尺寸整理为设计 tokens。
- 统一按钮、卡片、输入框、弹窗、状态标签和提示条。
- 同时支持浅色与深色主题。
- 不引入大型 UI 组件库，保持项目轻量。

## 4. R11 · 正式打包

目标不是只生成 `out/`，而是交付用户可以安装运行的 macOS 应用。

### 打包范围

- 配置 Electron 应用打包工具。
- 只发布 Apple Silicon（arm64）版本。
- 将 `SystemAudioDump` 正确放入应用资源并设置可执行权限。
- 配置麦克风、系统音频和屏幕相关的 macOS 权限说明。
- 验证生产环境下系统音频工具路径。
- 配置应用图标、应用标识、版本号和 DMG。
- 完成 Developer ID 签名、Hardened Runtime 和 Apple 公证。
- 验证首次启动、权限拒绝、重新授权、升级安装和卸载。
